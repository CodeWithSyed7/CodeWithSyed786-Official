## Features

- Featured project showcase
- Developer notes and learning journey
- Contact section and social links
- Print-ready resume page

## Technology assets

The `Assets/` directory contains SVG logos used by the technology marquee. Keep the relative paths and folder names unchanged unless the references in the compiled bundle are updated too.

## Deployment

This repository currently contains the production browser bundle rather than the original editable React source project. The root `index.html` is configured as the static deployment entry point and loads the compiled files from `code-with-syed.vercel.app/assets/`.

For a full source-level development workflow, restore the original source files and package manifest when they become available.
